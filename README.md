# CV MOZ — GitHub Pages

Esta pasta contém as páginas públicas da CV MOZ, exclusivamente em português: página inicial, Política de Privacidade, Termos de Utilização e instruções para eliminação de conta e dados.

Configure o GitHub Pages para publicar a branch `main`, pasta `/docs`. Consulte `../README-GITHUB-PAGES.md` para os passos de publicação. Antes de publicar, substitua `SEU-USUARIO` nos ficheiros `robots.txt` e `sitemap.xml` pelo seu nome de utilizador GitHub.
